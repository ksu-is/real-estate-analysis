# HausHackr: A Real-Estate Deal Analyzer

HausHackr is a Python tool that helps first-time buyers figure out if a duplex is a good house-hacking deal (live in one unit, rent out the other).

## What It Does
- Calculates the monthly mortgage payment (principal, interest, taxes, insurance, FHA mortgage insurance)
- Shows monthly cash flow after expenses
- Calculates cash-on-cash return, cap rate, and the 1% rule
- Compares multiple listings from a CSV file and ranks them
- Charts equity and cash flow over 30 years

## Who It's For
First-time buyers, especially those using FHA loans, who want a free and simple way to analyze a duplex before making an offer.
